# corticum

A real-time, parametric brain rendered entirely on the GPU.

There are **no textures, no meshes, no HDRIs and no animation data** in this
repository. Every surface, every fold, every vessel and every frame of disease
progression is generated by compute shaders at load time from a compact field
derived from real MRI.

The point is not just to draw a brain. It is to make the brain **parametric**,
so that changing a parameter simulates disease *properly* — stroke,
neurodegeneration, demyelination and mass lesions emerge from field
mathematics rather than being hand-animated.

> ⚠️ **Research and teaching visualisation only.** Nothing here is a validated
> clinical model. Parameters are tagged in the UI as `literature`, `derived` or
> `plausible-approximation`, and approximations say so explicitly.

## How it works

1. **Offline (Python, once).** A signed-distance field and a tissue-label field
   are derived from FreeSurfer's `fsaverage` `aparc+aseg` at native 1 mm and
   quantised to `int8`. The whole payload is **~2.2 MB gzipped** — real cortical
   folding, not an approximation of it.
2. **At load (WGSL compute).** The field is tricubically upsampled, given
   sub-voxel relief whose amplitude is modulated by *measured* sulcal depth,
   and turned into a curvature channel, a myelin channel, a generated vascular
   tree and an occupancy pyramid for empty-space skipping.
3. **Per parameter change (WGSL compute).** Three operator fields are rebuilt:
   an **offset** field (atrophy — adding a positive scalar to an SDF *is*
   erosion, so sulcal widening and ventricular enlargement emerge for free), a
   **velocity** field whose exponential gives a guaranteed-invertible
   deformation (mass effect, midline shift), and a **property** field
   (perfusion, water, blood, gliosis).
4. **Per frame.** A hand-written WGSL raymarch traces the composed field and
   writes true per-fragment depth, so GPU-extracted meshes for the ventricles,
   vessels and selected regions composite with it correctly in one pass.

Because every pathology writes into the *same* three fields, comorbidity works
without special-casing: a stroke in a Braak-V brain composes correctly.

## What it does

- **Four pathologies** — ischaemic stroke, neurodegeneration (Braak-staged AD,
  FTD, PD), demyelination, and mass lesions — all writing into the same three
  operator fields, so comorbidity composes without special-casing.
- **Per-region control.** `atrophy[r] = (braak[r] + ftd[r]) × vulnerability[r] +
  override[r]`, with regions groupable by lobe, Yeo-2011 network or hemisphere.
- **Time**, in the units each disease is actually discussed in — years for
  neurodegeneration, hours for acute stroke — with playback.
- **Arterial territories and a grown vascular tree.** Watershed zones are
  *derived*, not drawn: perfusion is a smoothed territory membership, so border
  zones fall out where two territories meet.
- **Synthetic radiological modalities** — T1, T2, FLAIR, DWI, CT — including the
  time dependence: a hyperacute infarct is bright on DWI while FLAIR is still
  negative, and invisible on CT for hours.
- **Clinical rating scales computed live** — ASPECTS, MTA, GCA, a Fazekas-like
  lesion load.
- **50 real patient presets** from the `stroke_qeeg` cohort, with qEEG band power
  projected onto the cortex.
- **Split comparison** — the same brain, healthy on one side of a divider and
  diseased on the other. A counterfactual, not a second scan.
- **Ground-truth NIfTI export** — synthetic T1, the composed distance field, and
  the *true* displacement field, for benchmarking registration or segmentation
  against a known answer.
- View tools: cutaway clip plane, radiological slice view, a magic lens that
  peels tissue rather than just magnifying, and >180° fisheye.

## Verified, not asserted

Every claim above has a gate behind it, runnable from the browser console.

| Gate | Result |
|---|---|
| Anatomy fidelity (GPU sample vs `aparc+aseg.mgz`) | **Dice 1.0000**, 0 differing voxels, 5 slices × 2 subjects |
| Deformation is a diffeomorphism | round-trip **0.0355 mm** worst case (threshold 0.1) |
| Clicking a gyrus names it | **20/20** agree with `aparc+aseg.mgz`, scored in Python |
| Braak staging | primary cortex spared until VI; hippocampal loss 27.3% at V |
| Stroke territory shape | worst **Dice 0.914**; contralateral core **0.000** |
| Collaterals spare the cortical rim | rim 95.7% → 68.7% while deep stays 100% → 99.9% |
| Vascular tree runs in its own territory | **0.922** agreement; branching is a real tree |
| DWI-FLAIR mismatch | DWI 1.208 vs FLAIR 1.013 at 2 h; FLAIR 1.131 by 48 h |
| ASPECTS | 10 healthy, 7 lacunar, 5 M2, 0 M1 |
| Split halves are real renders | pixel-identical (**0.000**) to a full render of each state |
| NIfTI export orientation | validated with **nibabel**, lesion lands in the commanded octant |
| Payload | **2.0 MB gzipped** at native 1 mm, 208³ |
| Shader validation | **29/29** chunks pass real Tint compilation, headlessly |

Two results worth reading as findings rather than features:

- **Collaterals alone do not rescue tissue, and early reperfusion alone does not
  either — only the combination does** (ASPECTS 0, 0, then 10). Nothing encodes
  that; it emerges from the core's growth rate meeting the collateral rescue
  term. It is the fast-progressor / slow-progressor distinction behind
  thrombectomy selection.
- **The qEEG delta/alpha ratio does not lateralise to the lesion in this
  cohort** — 54% across 46 unilateral patients, which is chance. Most of these
  strokes are subcortical or pontine and the recordings are chronic. The overlay
  is labelled as scalp topography mapped onto anatomy, not a lesion localiser.

Phase 0 (the de-risking spike) also passes end to end: compute writing a 3D
storage texture, a WGSL `ShaderMaterial` sphere-tracing it, two-way depth
compositing against rasterized geometry, GPU-generated vertex buffers, and
atomics with readback. Reachable at `#/spike`.

![Phase 0 spike](tests/artifacts/phase0_spike.png)

*The yellow probe sits between camera and isosurface and is visible; the magenta
probe sits behind it and is fully occluded — `fragDepth` compositing, measured
in pixels rather than eyeballed. The teal ring's vertices were generated on the
GPU and never touched the CPU.*

### Which brain?

`sample` (a real individual) is the default rather than the `fsaverage`
template, because averaging smooths gyri away. Measured with
`tools/prep/compare_subjects.py`:

| | fsaverage (average) | sample (individual) |
|---|---|---|
| isosurface area | 2010 cm² | **2684 cm²** |
| cortical grey matter | 338 cm³ | **494 cm³** |
| gyrification A/V^⅔ | 18.4 | **23.4** |

Switch with `#/?subject=fsaverage`.

## Develop

Requires Node 20.15+ and a WebGPU-capable browser (Chrome/Edge 113+).

```bash
npm install
```

```bash
npm run dev
```

Verify:

```bash
npm run build && npm run lint && npm run wgsl
```

`npm run wgsl` validates every hand-written WGSL chunk against **Tint**, the
same compiler Chrome uses, with no browser required.

The anatomical gates need a GPU, so they run from the browser console:

```js
await __corticum.verifyOperators()   // diffeomorphism, null-state identity
await __corticum.verifyStaging()     // Braak progression
await __corticum.verifyStroke()      // territory shape, laterality, collaterals
await __corticum.verifyModality()    // DWI-FLAIR mismatch, CT blind early
await __corticum.verifyAspects()     // ASPECTS, and the rescue interaction
await __corticum.verifySplit()       // halves are real renders
await __corticum.verifyExport()      // ground-truth export
await __corticum.verifyPicks(20)     // then: python tools/prep/verify_picks.py
```

Run them **back to back** — several real bugs only appeared in that order, each
passing in isolation.

Performance on the target GPU (GTX 1050 Ti, 4 GB): **16–18 ms at 1280×800** in
both art modes. The qEEG overlay costs about **0.08 ms**, measured off-vs-on
over batched frames.
